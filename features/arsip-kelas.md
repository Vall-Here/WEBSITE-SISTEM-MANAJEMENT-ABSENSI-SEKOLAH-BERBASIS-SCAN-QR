# 📂 Pengarsipan Kelas (Digital Archiving)

Menyimpan data catatan absensi dari ratusan hingga ribuan siswa setiap hari akan mengakumulasi besaran data (*bloatware*) pada server sekolah di tahun-tahun mendatang. EduConnect memperkenalkan sebuah paradigma pengelolaan basis data bernama **Sistem Arsip Kelas**.

![Menu Arsip Kelas](../assets/images/class-archive.png)
*(Gambar: Panel menu eksekusi pembersihan kelas dan pengarsipan)*

## Menjaga Performa Sistem Tetap Prima

Menjelang tahun ajaran baru atau momen kelulusan, sekolah biasa dihadapkan dengan perombakan data skala besar:
- Siswa naik kelas
- Siswa alumni yang dilepas dari sistem
- Riwayat absen tahun ajaran lama yang menjadi basi

Dengan menggunakan modul **Arsip Kelas**, admin sekolah bisa mengeksekusi "pembersihan".

## Bagaimana Modul ini Beroperasi?

1. **Ekskavasi Data:** Admin menekan tombol pengarsipan pada kelas spesifik (Misalnya XII IPA 1).
2. **Kompilasi Digital:** Sistem bekerja di latar belakang mengompilasi rekapitulasi lengkap semua murid di kelas tersebut dari absensi Hadir, Izin, Sakit, maupun Alpha di sepanjang tahun.
3. **Ekspor Hard-Copy Digital:** Keseluruhan data tersebut di-_dump_ (diekskresi) menjadi satu bundel file bereksistensi **Excel (.xlsx)**. File super ringan ini lalu disimpan rapi dalam direktori penyimpanan statis internal server.
4. **Pembersihan Bersih (Wiping):** Database operasional siswa yang berat akan dicuci hingga kembali menjadi 0 (nol). Server Anda tetap sekencang hari pertama kali membeli lisensi, meskipun sekolah telah meluluskan ratusan generasi.

## Mudah Diunduh Kapanpun
Anda membutuhkan catatan alumni dari 5 tahun yang lalu? File rekapan Excel akan selalu eksis dan berbaris rapi secara kronologis pada tabel riwayat arsip di panel Admin untuk dapat diunduh (Download) kapan saja tanpa khawatir akan hilang.
