\chapter{Modul Laporan \& Rekapitulasi}

Modul Laporan adalah ujung dari alur data EduConnect yang mengubah rekaman absensi mentah menjadi laporan terstruktur yang siap digunakan untuk keperluan administrasi akademis. Modul ini terbagi menjadi tiga sub-halaman: \textbf{Laporan Harian} (rekap per tanggal), \textbf{Laporan Bulanan} (rekap agregat per siswa per bulan, dengan ekspor Excel/Dapodik/PDF), dan \textbf{Laporan Per Siswa} (riwayat individu dengan tampilan kalender visual).

\section{Konsep Dasar \& Matriks Peran}
\begin{itemize}
    \item \textbf{Admin \& Super Admin}: Bebas melihat, menyaring, dan mengekspor seluruh rekaman kehadiran dari semua jenjang dan semua kelas tanpa batasan. Pilihan \textbf{Semua Kelas} pada \textit{dropdown} tersedia secara penuh.
    \item \textbf{Wali Kelas (\textit{Teacher})}: Menganut prinsip privasi data. Laporan terkunci secara mekanis dan hanya menghasilkan keluaran untuk kelas yang didelegasikan padanya. Opsi ``Semua Kelas'' pada \textit{dropdown} tidak akan menghasilkan data kelas lain.
\end{itemize}

\section{Skenario Dunia Nyata \& Alur Kerja}

Di akhir bulan November, Staf Bimbingan Konseling (BK) selaku Admin membuka EduConnect untuk sidak rekapitulasi. Fase 1: Staf BK masuk ke menu \textbf{Laporan Bulanan}, mengisi tahun \textit{2026} dan bulan \textit{11} pada filter, memilih kelas \textit{11 IPS 2}, lalu mengklik \textbf{Filter}. Tabel menampilkan daftar seluruh siswa kelas tersebut beserta kolom H (Hadir), T (Terlambat), I (Izin), S (Sakit), A (Alpha), dan persentase kehadiran. Fase 2: Staf BK menemukan Siswa C memiliki kolom A bernilai 5 dan persentase merah (di bawah 75\%). Fase 3: Ia berpindah ke sub-menu \textbf{Laporan Per Siswa}, mencari nama Siswa C, mengatur rentang tanggal bulan November, mengklik \textbf{Filter}, lalu mengklik tombol \textbf{Export Kartu Siswa (PDF)} untuk mencetak Surat Panggilan.

\section{Panduan Penggunaan (Step-by-Step)}

\subsection{Menarik Laporan Harian}
\begin{enumerate}
    \item Pada panel navigasi kiri, klik menu \textbf{Laporan Absensi}. Anda akan diarahkan ke sub-menu \textbf{Laporan Harian}.
    \item Atur filter \textbf{Tanggal} yang diinginkan menggunakan \textit{date picker}.
    \item Pilih \textbf{Kelas} dari \textit{dropdown} jika ingin mempersempit data hanya untuk satu kelas.
    \item Klik tombol \textbf{Filter} untuk menampilkan hasilnya. Tabel menampilkan rekap harian berisi nama siswa, NIS, kelas, jam masuk, jam keluar, status, dan metode absen.
    \item Gunakan tautan \textbf{Export Excel} (warna hijau) atau \textbf{Export PDF Harian} (warna ungu) untuk mengunduh laporan.
\end{enumerate}

\subsection{Menarik Laporan Bulanan (Excel / Dapodik / PDF)}
\begin{enumerate}
    \item Pada panel navigasi kiri, klik sub-menu \textbf{Laporan Absensi}, lalu klik tab \textbf{Laporan Bulanan}, atau langsung akses URL \texttt{/admin/reports/monthly}.
    \item Pada baris filter di atas tabel, isi isian angka \textbf{Tahun} (contoh: \texttt{2026}).
    \item Pilih \textbf{Bulan} dari \textit{dropdown} angka (1 sampai 12).
    \item Pilih \textbf{Kelas} dari \textit{dropdown}. (Catatan: Jika Anda \textit{login} sebagai Wali Kelas, hanya kelas asuhan Anda yang tersedia).
    \item Klik tombol \textbf{Filter} (warna hijau \textit{emerald}). Tabel akan muncul di bawah baris filter, menampilkan kolom: \textbf{NIS}, \textbf{Nama}, \textbf{Kelas}, \textbf{H} (Hadir), \textbf{T} (Terlambat), \textbf{I} (Izin), \textbf{S} (Sakit), \textbf{A} (Alpha), dan \textbf{\%} (Persentase Kehadiran). Persentase di bawah 75\% ditandai merah, di atas 75\% ditandai hijau.
    \item Di atas tabel, terdapat tiga tombol ekspor:
    \begin{itemize}
        \item Klik tombol \textbf{Export Excel} (bingkai \textit{emerald}) untuk mengunduh rekap dalam format \textit{spreadsheet}.
        \item Klik tombol \textbf{Export Dapodik} (bingkai \textit{teal}, hanya muncul jika kelas dipilih) untuk mengunduh rekap dalam format khusus pelaporan Dapodik Kemendikbud.
        \item Klik tombol \textbf{Export PDF Bulanan} (bingkai \textit{indigo}) untuk mengunduh laporan dalam format PDF siap cetak.
    \end{itemize}
\end{enumerate}

\subsection{Meninjau Riwayat Individu (Laporan Per Siswa)}
\begin{enumerate}
    \item Akses sub-menu \textbf{Laporan Absensi} $\rightarrow$ \textbf{Laporan Per Siswa}, atau langsung ke URL \texttt{/admin/reports/student}.
    \item Pada baris filter, pilih nama siswa dari \textit{dropdown} \textbf{Pilih Siswa} (berisi nama dan NIS).
    \item Isi \textbf{Tanggal Mulai} dan \textbf{Tanggal Selesai} pada dua isian \textit{date picker}.
    \item Klik tombol \textbf{Filter} (warna ungu \textit{violet}). Halaman akan menampilkan:
    \begin{itemize}
        \item Kartu identitas siswa (Nama, NIS, Kelas).
        \item Empat kartu ringkasan: \textbf{Hadir} (hijau), \textbf{Terlambat} (kuning), \textbf{Izin/Sakit} (biru), \textbf{Alpha} (merah).
        \item \textbf{Kalender Status}: Grid visual yang menampilkan setiap hari dalam rentang tanggal, masing-masing diwarnai sesuai statusnya.
        \item Tabel detail harian berkolom: \textbf{Tanggal}, \textbf{Status}, \textbf{Masuk}, \textbf{Pulang}, \textbf{Metode}, dan \textbf{Catatan}.
    \end{itemize}
    \item Di atas tabel, terdapat dua tombol ekspor:
    \begin{itemize}
        \item \textbf{Export Daftar Siswa (Excel)}: Mengunduh data seluruh siswa aktif di sekolah dalam format Excel.
        \item \textbf{Export Kartu Siswa (PDF)}: Mengunduh kartu identitas berisi QR Code siswa yang sedang dipilih dalam format PDF.
    \end{itemize}
\end{enumerate}

\section{Penanganan Masalah (Edge Cases)}
\begin{itemize}
    \item \textbf{Tabel Laporan Bulanan Kosong Setelah Filter}: Pastikan parameter Tahun dan Bulan yang dimasukkan sesuai dengan rentang data yang tersedia. Jika kelas baru dibuat di pertengahan bulan, data sebelum tanggal pembuatan kelas tidak akan tersedia.
    \item \textbf{Risiko Beban Server Saat Ekspor}: Jangan mengosongkan filter \textbf{Kelas} lalu langsung mengunduh Excel Laporan Bulanan jika sekolah memiliki ratusan kelas atau ribuan murid aktif. Lakukan ekspor secara bertahap (per kelas) untuk menjaga stabilitas \textit{server}.
    \item \textbf{Tombol Export Dapodik Tidak Muncul}: Tombol ini dirancang hanya muncul saat filter Kelas sudah dipilih (bukan ``Semua Kelas''), karena format Dapodik memerlukan data satu kelas spesifik.
\end{itemize}
